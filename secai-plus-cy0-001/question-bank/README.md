# Question Bank — SecAI+ (CY0-001)

Practice questions organized by exam domain. Questions sourced from Banks 1 & 2 (120 total). Each domain directory contains markdown files with questions, answers, and full explanations.

## Question Format

Each question uses collapsible answer sections so you can test yourself before revealing the answer:

```markdown
### Q1. [Question Title]

[Question text]

- A) Option A
- B) Option B
- C) Option C
- D) Option D

<details>
<summary>Answer</summary>

**B) Option B**

Explanation of why this is correct and why others are wrong.
</details>
```
