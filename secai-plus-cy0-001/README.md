# CompTIA SecAI+ (CY0-001)

CompTIA's first certification focused on securing, governing, and responsibly integrating AI into cybersecurity operations.

## Exam Details

| Detail | Info |
|--------|------|
| **Exam Code** | CY0-001 |
| **Launch Date** | February 17, 2026 |
| **Questions** | Max 60 (multiple-choice + performance-based) |
| **Duration** | 60 minutes |
| **Passing Score** | 600 / 900 |
| **Recommended Experience** | 3–4 years IT, 2+ years cybersecurity |
| **Prerequisites (Recommended)** | Security+, CySA+, PenTest+, or equivalent |
