# CompTIA Security+ (SY0-701)

The industry-standard entry-level cybersecurity certification, meeting DoD 8570/8140 requirements.

## Exam Details

| Detail | Info |
|--------|------|
| **Exam Code** | SY0-701 |
| **Launch Date** | November 7, 2023 |
| **Questions** | Max 90 (multiple-choice + performance-based) |
| **Duration** | 90 minutes |
| **Passing Score** | 750 / 900 |
| **Recommended Experience** | CompTIA Network+, 2 years IT security experience |
| **Retirement** | Estimated 2026 |
